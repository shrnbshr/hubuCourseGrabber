# 湖北大学强智教务系统（jsxsd）自动抢课助手

灵感来自[Auto_courseGrabber](https://github.com/ceilf6/Auto_courseGrabber)，使用Google Antigravity针对强智教务系统进行适配和优化。

面向**湖北大学教务管理系统选课页面**（强智科技 `jsxsd` 架构）的自动化抢课工具。针对湖北大学选课系统的 **jQuery DataTables（`#dataView`）**、**`queryKxkcList()` 异步局部查询机制** 以及 **多层嵌套 iframe 架构** 进行了深度定制与交互极简优化。

---

## ⚡ 极简使用流程（首选推荐）

此方式**免开 F12**、**免复制代码**、**免输长串课程代码**，配置一次后续全自动：

### 1. 安装油猴插件并开启“开发者模式”
1. 浏览器安装 [Tampermonkey（油猴插件）](https://www.tampermonkey.net/)（Chrome 或 Edge 扩展商店搜索安装）。
2. **重要前提**：在浏览器地址栏打开 `chrome://extensions/`（Edge 打开 `edge://extensions/`），将页面右上角的 **“开发者模式” 开关拨至开启**（若关闭，浏览器会静默阻止油猴运行）。

### 2. 导入抢课脚本
1. 点击浏览器右上角油猴图标 -> 选择 **“添加新脚本”**。
2. 打开本地文件 [`hubuCourseGrabber.user.js`](hubuCourseGrabber.user.js)，全选复制其全部内容。
3. 粘贴到油猴编辑器中，按键盘快捷键 **`Ctrl + S`**（保存）。

### 3. 打开选课页一键开抢
1. 登录教务系统后，直接进入选课入口页面：
   - 选课直达链接：`https://jwxt.hubu.edu.cn/jsxsd/xsxk/xsxk_index?jx0502zbid=5A25EAACE4F240A3BD55041C605C605D`
2. 页面右上角会**自动弹出单个 HUBU 抢课助手面板**（已具备跨 Frame 锁，绝不重复弹窗）。
3. 在下方课程表格中找到目标课程，**直接点击该行最右侧的【⚡ 抢这门】按钮**。
4. 脚本会自动将该课程加入监控队列并立即开启自动监控；一旦有人退课释放名额，脚本毫秒级自动提交选课并跳过所有确认弹窗。

## 🛠️ 备选方式：控制台临时运行（无需安装插件）

在不方便安装浏览器扩展的电脑上，可通过 F12 直接运行：

1. 登录教务系统进入选课列表页，在筛选条件中**取消勾选“过滤已满课程”**，点击“查询”使课程表格完整展示。
2. 按键盘 **`F12`**（或右键 -> 检查），切换到 **Console（控制台）** 标签页。
3. 复制 [`hubuCourseGrabber.js`](hubuCourseGrabber.js) 文件的全部代码，粘贴进控制台并按回车。
4. 运行后，页面表格右侧同样会自动注入 **【⚡ 抢这门】** 按钮，点击即可开抢。

## ✨ 核心特性

- **行内一键点选**：自动在 `#dataView` 课程表格每一行末尾注入【⚡ 抢这门】快捷按钮，点击即抢，告别手动抄写长串数字代码。
- **跨 Frame 单例锁**：强智选课页由导航、列表、作息时间表三个 Frame 拼接而成，脚本内置单例锁，自动过滤课表等辅助 Frame，全屏严格只展示 1 个控制面板。
- **静默后台刷新**：轮询中自动调用教务系统自带的 `queryKxkcList()` 异步拉取最新数据，无需刷新整个网页，不卡顿、不重载。
- **课表冲突前置识别**：自动分析表格状态列中“与已选课程冲突”说明，遇冲突课程前置过滤跳过，无需提交后等待后台报错。
- **双重弹窗自动放行**：同时接管浏览器原生 `confirm` 弹窗与强智系统的 EasyUI 对话框（`panel window`），自动点击“确定”，全程无人值守。
- **定时毫秒开抢**：针对未开放选课的场景，可预设未来开抢时间，毫秒级倒计时，到点自动唤醒并发起冲刺。

## 💻 命令行接口（Console CLI）

在控制台中可随时使用 `window.hubuGrab` 提供的调试接口：

```javascript
// 1. 扫描当前页面表格各列数据及识别情况
hubuGrab.debug();

// 2. 精准测试指定课程代码的解析（查看余量、冲突状态与选课按钮）
hubuGrab.debug('9000111001');

// 3. 手动启动 / 停止抢课
hubuGrab.start();
hubuGrab.stop();

// 4. 重新显示悬浮控制面板
hubuGrab.showUI();
```

## ❓ 常见问题

1. **油猴安装后页面没有反应？**
   - 检查浏览器扩展设置（`chrome://extensions` 或 `edge://extensions`）右上角的 **“开发者模式”** 是否开启。
   - 检查油猴编辑器保存后是否显示为启用状态。
2. **为什么表格里部分课程余量为 0 但点【⚡ 抢这门】没反应？**
   - 余量为 0 时点击【⚡ 抢这门】，脚本会将该课加入**自动监控队列**并开始高速轮询捡漏。一旦有同学退课产生余量，脚本会瞬间秒杀提交。
3. **安全与频率建议**：
   - 默认轮询间隔为 `1200ms`，兼顾捡漏响应速度与学校服务器网关稳定性，不建议调至 `600ms` 以下。
